Privacy reminder: Preserved Simply Plural data is private System data. Keep exports and backups somewhere safe and under your own control. Please do not send us tokens, passwords, export files, screenshots, or private System data.

Contact

Contact PluralBridge without sending private System data.

PluralBridge is an independent project focused on helping plural Systems protect preserved Simply Plural data and move toward the first browser-based release.

Email is fine for general questions, project follow-up, contributor interest, and public-site issues.

Responses are best-effort and not real-time support.

Before you contact us

Please do not send Simply Plural tokens, passwords, export files, screenshots, private notes, member records, avatar files, fronting history, account details, or other private System data.

A useful message can describe the general situation without including private data. For example: what page you were reading, what kind of help you are looking for, what browser or operating system you are using, or whether you are asking as a user, contributor, reviewer, tester, or community contact.

Which address to use

  • Use info@thepluralbridge.org for general project questions, site feedback, and community follow-up.
  • Use support@thepluralbridge.org for non-private questions about the public guidance pages.
  • Use GitHub Discussions first for contributor and workflow conversations so context stays public and reusable.

General contact

For general questions about PluralBridge, the public website, project direction, community follow-up, or non-private coordination, email info@thepluralbridge.org.

Support questions

For non-private support questions about the public guidance pages, email support@thepluralbridge.org.

Keep the question general. If explaining the issue safely is hard, start by asking how to describe the problem without private data.

Contributor and developer questions

Developers, reviewers, testers, documentation helpers, accessibility reviewers, security-minded contributors, and privacy-minded contributors should start with GitHub Discussions so project context remains public and searchable.

If you do not have an export file

Recovery is case-by-case and device-dependent. Some paths are working now, and others are still being tested.

  • Samsung Galaxy S24+ data extraction: available now.
  • Samsung Galaxy S24+ avatar recovery: not available yet.
  • Google Pixel 10a: investigation started.
  • Apple iPhone 16: recovery path investigation in progress.

For current status and recovery guidance, use Data Recovery and Simply Plural shutdown and data preservation.

Not emergency support

PluralBridge is not emergency support. Do not use PluralBridge contact addresses for crisis, safety, medical, legal, or emergency requests.

If you or someone else is in immediate danger, call your local emergency number now (for example, 911 in the US/Canada, 112 in many EU countries, or 999 in the UK/Ireland).

If you are in emotional distress, contact a local crisis support service in your country.

Project boundary

PluralBridge is an independent project. It is not affiliated with Simply Plural, Apparyllis, or the Simply Plural development team.

PluralBridge will be a free service at no cost to the plural community. Please do not send us money.
