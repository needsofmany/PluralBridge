# Simply Plural Shutdown and Data Preservation — Archived

This guide is retained as part of PluralBridge's project history.

The Simply Plural shutdown has occurred. Simply Plural's servers are no longer available, and the legacy PluralBridge export tooling cannot create a new export.

If you already preserved your Simply Plural data, keep the export private, backed up, and somewhere under your control.

For current information:

- [Simply Plural shutdown information](/simply-plural-shutdown.html)
- [Export guidance](/export-now.html)
