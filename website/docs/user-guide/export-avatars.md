# Export Simply Plural Member Avatars — Archived

This guide is retained as part of PluralBridge's project history.

Simply Plural's servers are no longer available. The legacy avatar export procedure can no longer retrieve member images from Simply Plural.

If you already preserved avatar files or a Simply Plural export containing avatar data, keep those files private, backed up, and somewhere under your control.

For current information:

- [Export guidance](/export-now.html)
