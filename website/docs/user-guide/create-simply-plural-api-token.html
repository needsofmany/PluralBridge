Create a Simply Plural API Token — Archived

This guide is retained as part of PluralBridge's project history.

Simply Plural's servers are no longer available. Creating a Simply Plural API token is no longer part of the PluralBridge workflow, and the legacy export tooling cannot create a new export.

If you already preserved your Simply Plural data, keep that export private, backed up, and somewhere under your control.
