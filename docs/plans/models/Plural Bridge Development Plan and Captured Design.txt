RELEVANT FRONTEND RESPONSIBILITIES

app/src/js/legacy-app.js:
Builds Members workspace/panel frame, header and pin.
Contains createMemberAccordion and exposes it through
window.PluralBridge.createMemberAccordion.

app/src/js/navigator.js:
Tree rendering, selection, expansion, profile loading, right-pane rendering.

app/src/js/members.js:
Toolbar including the currently named “Systems” visibility toggle.

app/src/js/api-client.js:
readAnchorMemberProfiles(objectType, anchorName, signal).

createMemberAccordion(profile, { allowProfileEditing: false }) is used for
this pane. It omits edit/save controls and avoids old current-system writes.

Procedure error numbers:
50001 missing/blank input
50002 unsupported anchor type
50003 missing/ambiguous account email
50004 anchor absent from that account’s map
50005 multiple matching map anchors by type/name
50006 no access membership
50007 multiple matching access memberships
50008 membership inactive or status unresolved

HTTP mapping:
50001,50002,50005,50007 → 400
50004 → 404
50006,50008 → 403
50003 and other SQL errors → fixed 500
Match SqlException.Number, not message text.
